# Summit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App de escritorio para Windows que muestra en vivo un monitor elegido dentro de su ventana, con zoom, punto de foco de 9 posiciones y límite de FPS.

**Architecture:** `Summit.Core` (net10.0) tiene la lógica pura y testeable: cálculo del recorte/encuadre, limitador de cuadros y configuración. `Summit` (WinForms) tiene la ventana, la captura con Windows.Graphics.Capture y el dibujo con Direct3D 11: el cuadro capturado queda en la placa de video y se dibuja con un triángulo de pantalla completa cuyo shader muestrea el sub-rectángulo que define el zoom. Solo se dibuja cuando llega un cuadro nuevo o cambia un control.

**Tech Stack:** C# / .NET 10, WinForms, Windows.Graphics.Capture (CsWinRT), Vortice.Direct3D11 / Vortice.DXGI / Vortice.D3DCompiler, xUnit.

**Spec:** `docs/superpowers/specs/2026-11-15-summit-design.md`

## Global Constraints

- Nombre de la app, ventana y ensamblado: `Summit`.
- Zoom: 1x a 8x, pasos de 0.1.
- FPS: 15 / 30 / 60 / 120 / máximo (0 = sin límite).
- Foco: 9 puntos, ancla `(x, y)` con cada componente en {0, 0.5, 1}.
- Sin arrastre de imagen, sin pantalla completa, sin atajos globales.
- Ninguna mención a juegos en interfaz, textos ni código.
- La ventana arranca maximizada, con barra de título.
- Configuración en `%AppData%\Summit\settings.json`.
- SO mínimo: Windows 10 2004 (19041). APIs más nuevas (`IsBorderRequired`, `MinUpdateInterval`) se usan solo si están presentes.
- DPI: PerMonitorV2.
- No se hacen commits salvo que el usuario lo pida.

## Review Focus

1. Archivo de configuración corrupto o con valores fuera de rango → la app abre con valores por defecto/acotados (test en Task 1).
2. Ventana minimizada o panel de tamaño 0 → no se dibuja ni se redimensiona, sin excepción (test de `ViewMath.Letterbox` con tamaño 0 en Task 1; guarda en Task 3).
3. El monitor capturado cambia de resolución → se recrea el pool de cuadros con el tamaño nuevo (Task 3, verificación manual).
4. El monitor elegido se desconecta → la lista se refresca y se pasa a otro monitor disponible (Task 4, verificación manual).
5. El monitor guardado en la configuración ya no existe al abrir → se elige otro (test de `MonitorChoice.Pick` en Task 1).

```csharp
namespace Summit.Core;
public readonly record struct RectF(float X, float Y, float Width, float Height);
public static class ViewMath {
    public const float MinZoom = 1f, MaxZoom = 8f;
    // Sub-rectángulo de la fuente en coordenadas 0..1.
    public static RectF SourceRect(float zoom, float anchorX, float anchorY);
    // Rectángulo destino en píxeles, centrado y con la proporción de la fuente. Tamaños <= 0 → RectF vacío.
    public static RectF Letterbox(int srcW, int srcH, int dstW, int dstH);
}
public sealed class FrameLimiter {
    public int Fps { get; set; }               // 0 = sin límite
    public bool ShouldRender(long nowTicks);   // ticks de Stopwatch; registra el cuadro si devuelve true
    public FrameLimiter(long ticksPerSecond);
}
public sealed class Settings {
    public string? Monitor { get; set; }       // DeviceName
    public string? WindowScreen { get; set; }
    public float Zoom { get; set; } = 2f;
    public float AnchorX { get; set; } = 0.5f;
    public float AnchorY { get; set; } = 0.5f;
    public int Fps { get; set; } = 60;
    public static readonly int[] FpsOptions = [15, 30, 60, 120, 0];
    public void Normalize();                   // acota zoom, ajusta anclas a {0,.5,1}, Fps inválido → 60
    public static Settings Load(string path);  // archivo faltante o corrupto → valores por defecto
    public void Save(string path);             // crea la carpeta
    public static string DefaultPath { get; }
}
public static class MonitorChoice {
    // Devuelve saved si está en available; si no, el primero distinto de ownScreen; si no, el primero. Lista vacía → null.
    public static string? Pick(string? saved, IReadOnlyList<string> available, string? ownScreen);
}
```

### Task 3: Captura y dibujo

**Files:**
- Create: `src/Summit/Capture/CaptureInterop.cs` (COM: `IGraphicsCaptureItemInterop`, `IDirect3DDxgiInterfaceAccess`, `CreateDirect3D11DeviceFromDXGIDevice`)

**Interfaces (Produces):**

```csharp
sealed class Mirror : IDisposable {
    Mirror(IntPtr viewHwnd);
    void SetMonitor(IntPtr hmonitor);          // reinicia la sesión de captura
    void SetView(float zoom, float anchorX, float anchorY);   // redibuja
    void SetFps(int fps);                      // 0 = sin límite
    void Resize(int width, int height);        // <= 0 → no hace nada
    static bool IsSupported { get; }
}
```

- [ ] **Step 1:** Dispositivo D3D11 (BGRA), swap chain flip-discard para `viewHwnd`, shaders compilados al inicio: VS de triángulo de pantalla completa, PS que muestrea con filtro lineal usando `uvOffset`/`uvScale` de un constant buffer.
- [ ] **Step 2:** Captura: `GraphicsCaptureItem` del monitor, `Direct3D11CaptureFramePool.CreateFreeThreaded` (BGRA8, 2 buffers), cursor habilitado, `IsBorderRequired = false` y `MinUpdateInterval` si existen. En `FrameArrived`: tomar el cuadro; si `ContentSize` cambió, `Recreate`; si `FrameLimiter.ShouldRender` es false, descartar; si no, reemplazar el cuadro retenido y dibujar.
- [ ] **Step 3:** `Render()` bajo un lock: limpia a negro, viewport = `ViewMath.Letterbox`, UV = `ViewMath.SourceRect`, dibuja, `Present(0)`. Con tamaño 0 o sin cuadro retenido, no hace nada. Un error de dispositivo perdido reinicia el pipeline una vez.
- [ ] **Step 4:** `dotnet build` sin errores.
